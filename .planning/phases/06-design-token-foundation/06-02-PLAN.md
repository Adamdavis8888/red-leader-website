  <name>Task 1: Replace Inter with Geist Sans + Geist Mono font loading</name>
  <files>app/layout.tsx</files>
  <action>
Update app/layout.tsx to replace Inter with Geist Sans and Geist Mono:

1. Replace imports:
   - Remove: `import { Inter } from 'next/font/google'`
   - Add: `import { Geist, Geist_Mono } from 'next/font/google'`

2. Replace font initialization:
   - Remove the `inter` constant
   - Add:
     ```tsx
     const geistSans = Geist({
       variable: '--font-geist-sans',
       subsets: ['latin'],
     })

     const geistMono = Geist_Mono({
       variable: '--font-geist-mono',
       subsets: ['latin'],
     })
     ```
   - Geist loads as a variable font by default (all weights including 400 regular and 600 semibold). Do NOT pass a `weight` option — the default variable font behavior is what we want.

3. Update the <html> tag className:
   - Replace: `className={inter.variable}`
   - With: `className={`${geistSans.variable} ${geistMono.variable}`}`

4. Keep everything else unchanged: metadata, plausible script, body className ("font-sans antialiased"), children rendering.

The CSS variable names MUST be exactly `--font-geist-sans` and `--font-geist-mono` — these are referenced by globals.css @theme inline `--font-sans: var(--font-geist-sans)` and `--font-mono: var(--font-geist-mono)`.
  </action>
  <verify>
1. `npx next build 2>&1 | tail -5` — build must succeed
2. `grep 'Geist' app/layout.tsx` — should show Geist and Geist_Mono imports
3. `grep 'Inter' app/layout.tsx` — should return nothing (fully removed)
4. `grep 'font-geist-sans' app/layout.tsx` — confirms correct CSS variable name
5. `grep 'font-geist-mono' app/layout.tsx` — confirms Mono variable
  </verify>
  <done>
